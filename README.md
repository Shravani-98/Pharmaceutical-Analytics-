# ✨ Project Overview

The **Pharmaceutical Sales Dashboard** is an interactive Power BI project designed to analyze pharmaceutical sales performance using dynamic KPIs, business intelligence techniques, and modern dashboard visualizations.

This dashboard transforms raw pharmaceutical data into meaningful insights that help businesses monitor sales trends, track product performance, and improve decision-making.

---

# 🎯 Business Problem

Pharmaceutical companies generate large volumes of sales data daily. Without proper analysis:

- Tracking sales growth becomes difficult
- Manual reporting consumes time
- Top-performing products are hard to identify
- Regional performance analysis becomes complex
- Business decisions may become inaccurate

---

# ✅ Solution

This Power BI dashboard provides:

✔️ Interactive KPI Monitoring

✔️ Regional Sales Insights

# 🧠 DAX Measures

```DAX
Total Sales = 
SUM(Sales[Revenue])

Total Orders = 
COUNT(Sales[Order_ID])

Profit Margin = 
DIVIDE(
    SUM(Sales[Profit]),
    SUM(Sales[Revenue]),
    0
)
```
